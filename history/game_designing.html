About Game Designing

Create a game with the theme of embracing diversity using game development tools such as GreenFoot, Stencyl, Torque 3D, Gamebryo, Build Box, Pfile, etc.

Rules

  • Number of teams per school: Maximum 2
  • Number of participants per team: 2
  • Duration: 8:00 am to 12:00 pm
  • Resources: Participants should bring a laptop with the necessary software installed.
  • Laptops should not have any pre-built game or parts of the game.
  • Prior Knowledge: Participants should have prior knowledge of game development tools such as GreenFoot, Stencyl, Torque 3D, Gamebryo, Build Box, Pfile, etc.
  • Grade Level: 9-12
